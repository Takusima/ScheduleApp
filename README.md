# ScheduleApp

Расписание для КМК. Проект сохраняет стабильное Android-приложение 0.2 и постепенно переносит интерфейс и общую логику на Kotlin Multiplatform / Compose Multiplatform для Android и iOS.

## Текущее состояние

- Стабильная Android-версия 0.2 остаётся в модуле `app`.
- Кроссплатформенный интерфейс разрабатывается в `composeApp`.
- В ветке `feature/student-dashboard-kmp` добавлен начальный экран с навигацией, ручным журналом оценок и списком задолженностей.
- Данные журнала пока хранятся только в памяти процесса. Постоянное локальное хранилище и подключение к существующему расписанию — следующие этапы.
- Не устанавливайте экспериментальную KMP-версию вместо стабильного APK, пока не будет проверена интеграция и подпись обновления.

## Правила разработки

1. Изучать существующий код до изменений и не переписывать рабочие части без необходимости.
2. Сохранять стабильную версию и делать кроссплатформенную работу в отдельной ветке.
3. Не менять `applicationId = "com.taku.schedule"` без явного решения.
4. Не считать сборку проверенной, пока CI фактически не завершился успешно.
5. Не выпускать APK с временной debug-подписью как обновление для пользователей.
6. Вести историю изменений в этом файле и в `CHANGELOG.md`.

## Следующие шаги
