# Расписание — Android

Готовый исходный проект приложения для Android.

Источник: https://cloud.mail.ru/public/vH1B/7LrFtqWqP

Функции:
- автоматическая синхронизация папки Mail Облака;
- скачивание XLSX из публичной папки через API архивирования;
- выбор группы;
- выбор даты;
- выбор файла по дате начала;
- локальный кэш;
- красивый тёмный интерфейс;
- работа с несколькими Excel-файлами;
- fallback-отображение строк Excel, если структура конкретного файла отличается.

Для сборки нужен Android SDK и Gradle 8.9+ с JDK 17+.
